## 兩者怎麼連在一起

TWSA **只讀**台股雷達 `00money\data\` 裡的資料，**不會修改、不會覆蓋**任何檔案：

- `px_history.json`、`kline\` → 行情
- `inst_hist.json` → 三大法人
- `history.json` → 月營收
- `groups.csv` → 你的族群（變成選股範圍「族群：○○」）
- `watchlist.json` → 自選股

所以平常照舊用台股雷達更新資料，TWSA 打開就是最新的。兩個網站可以同時開著。

## 為什麼沒有合併成一支

`tw_radar.py` 有 3.5MB，在雲端無法完整讀取，也不能覆寫你 Dropbox 裡既有的檔案；
在沒看懂全貌的情況下修改一支每天在用的大程式，風險太高。
若之後想合併成一套（把選股回測變成台股雷達網站的分頁），建議在你自己的電腦上用 Claude Code 開 `00money` 資料夾來做。

## 第一次使用

1. 雙擊 `install.bat`（安裝 pandas、requests、openpyxl 等套件）
2. 雙擊 `start_demo.bat` 先看模擬資料的畫面
3. 雙擊 `start_dashboard.bat` 用台股雷達的真實資料
4. 到「個股查詢」看「資料來源」是不是「台股雷達本機資料」；不是的話把畫面截圖給我

## 不要了怎麼辦

直接刪掉整個 `00_TWSA` 資料夾即可，台股雷達完全不受影響。

詳細說明見 `README.md`。
