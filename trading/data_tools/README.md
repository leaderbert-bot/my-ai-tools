# data_tools：補兩種回測缺的資料

這兩支要放進 `00money` 資料夾（跟 tw_radar.py 同一層）在你的電腦上跑。雲端連不到永豐和證交所。

| 檔案 | 做什麼 | 解開哪些策略 | 時間 |
|---|---|---|---|
| `stk1m_dl.py` + `下載個股分K.bat` | 用永豐 Shioaji 只抓「事件日」的個股 1 分 K：收盤鎖漲停 D 與 D+1、飆股 D 與 D+1、處置期間每天 | 鎖漲停隔天開高空、恐慌急殺隔天、處置股盤中轉折、搶漲停隔日沖 | 2020 起約 58,000 筆 (代號,日期)，每筆約 25 KB。永豐每日流量有上限，會分幾天跑完；重跑接著抓 |
| `inst10_dl.py` + `十年三大法人.bat` | 用雷達同一支 `fetch_inst_day` 補 2016 起每天的三大法人買賣超 | ★ 加法人籌碼條件（投信連買、外資轉買、法人占成交量比） | 約 2,400 天 × 1.5 秒 ≈ 2～3 小時 |

## 用法

1. 兩個 .py 和兩個 .bat 複製到 `00money`。
2. 雙擊 `.bat`。中途關掉沒關係，再雙擊會接著抓。
3. 兩台電腦可以同時跑：每台只寫自己名字的檔（例如 `stk1m_2024-01.love.json.gz`），抓的順序用電腦名錯開，重複的很少。回測載入時把同一個月所有電腦的檔合起來讀。

### 個股分 K 的選項

```bat
python stk1m_dl.py --list                 :: 只算要抓幾筆，不登入
python stk1m_dl.py --next-only            :: lock/panic 只抓隔天那天（做交易那天），量減半
python stk1m_dl.py --since 2022-01-01     :: 改起點（預設 2020-01-01，永豐大約從 2020 起有分 K）
python stk1m_dl.py --kinds lock,punish    :: 只抓某幾類
python stk1m_dl.py --touch                :: 也抓「盤中碰到漲停沒鎖住」（多 3 萬多筆）
```

事件條件照 `tw_radar._xl_setups`：20 日均量 ≥ 500 張、股價 ≥ 10；鎖漲停＝收 ≥ 昨收 × 1.094 且收＝最高；
飆股＝近 4 天 ≥ 3 天漲 ≥ 5%、沒有一天 |漲跌| < 2%、5 日累積 ≥ 18%。

在雲端用你 Dropbox 的 k10y 乾跑過：2020 起 lock 30,017、panic 6,348、處置 912 個 (代號,日期)。

## 輸出格式

`data/stk1m/stk1m_YYYY-MM.<電腦名>.json.gz`
```json
{"done": {"2330|2024-01-02": 270}, "bars": {"2330": {"2024-01-02": {"t": ["09:00", "09:01"], "o": [], "h": [], "l": [], "c": [], "v": [], "k": ["lock+1"]}}}}
```

`data/inst10/inst10_YYYY.<電腦名>.json.gz`
```json
{"days": {"2024-01-02": {"2330": [外資, 投信, 自營]}}, "empty": ["2024-01-01"]}
```

抓好之後跟 Claude 說「個股分K抓好了」或「三大法人抓好了」，就可以開始驗。
